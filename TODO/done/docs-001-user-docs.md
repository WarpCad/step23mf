## Goal

Someone who finds the package on npm can install it, convert a file, and understand what survives the
conversion, without reading the source.

## Spec

- `README.md`: install (`npm i -g step23mf` and `npx step23mf`), a 3-line quick start, and the full `--help`
  text, generated by running the CLI rather than copied by hand. Links to the pages below.
- `docs/usage.md`: a step-by-step example on a STEP file the reader can get (a fixture path from
  `occt-import-js`, or a public CAx-IF file with its URL). The example shows the command, the exact stdout line,
  and how to check the result. Sections: output path and `--force`, assemblies, per-face colors, smoother curves.
- `docs/limitations.md`: what is kept and what is lost.
  - Kept: names, part and face colors, millimetre geometry, and assembly grouping (if core-003 chose it).
  - Lost: exact B-rep (output is triangles), PMI/annotations, transparency, layers and materials beyond color,
    and shared instances (written as copies).
  - Also covers how names are derived (`(k)` suffix, `Part N`) and why colors are converted back from linear RGB.
- `docs/compatibility.md` from 3mf-002, brought up to date with the final encoding.

## Testing

Every command in `README.md` and `docs/usage.md` is run, and its output compared with the page. A doc example
that no longer produces what the page says is a bug. Optional: `test/docs.spec.js` checks that the `--help`
block in README matches `USAGE` exactly.
