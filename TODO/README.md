# TODO

One file per open task, named `<area>-<nnn>-<slug>.md` (areas: `core`, `step`, `3mf`, `cli`, `docs`, `build`).
Finished tasks move to `TODO/done/`. `ROADMAP.md` is the ordered list of open work.

A task file holds: **Goal**, **Spec** (inputs, outputs, degenerate cases), **Testing** (named specs and
fixtures), **Docs**, and **Acceptance** (which `ACCEPTANCE.md` scenarios it re-runs).
